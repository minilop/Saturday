# Project Context

このプロジェクトは、AWS上で稼働しているPython BatchシステムをGCPへ移行するプロジェクトである。

既存のAWS環境で使用している各種サービスをGCPの対応するサービスへ移行し、Python BatchのコードもGCP環境に対応するように修正する。

## AWS to GCP Service Mapping

| AWS | GCP | Migration |
|---|---|---|
| Amazon Redshift | BigQuery | RedshiftからBigQueryへ移行 |
| Amazon S3 | Google Cloud Storage (GCS) | S3からGCSへ移行 |

## Migration Guidelines

- Redshiftに依存しているSQL、データアクセス処理、接続処理などはBigQuery向けに変更する。
- S3に依存しているファイルアクセス、アップロード、ダウンロードなどの処理はGCS向けに変更する。
- AWS SDKやAWS固有のAPIを使用しているコードは、必要に応じてGCPのSDKやAPIへ置き換える。
- AWS固有の認証・接続方式は、GCP環境に適した認証・接続方式へ変更する。
- AWSからGCPへの移行によって必要となる変更以外は、既存の業務ロジックや処理フローを可能な限り維持する。
- 移行後のコードは実際に実行し、エラーやテスト結果を確認する。
- エラーが発生した場合は、エラーメッセージを分析して原因となるコードを特定し、必要な修正を行った上で再実行する。

## Migration Goal

AWS環境で実行されていたPython Batchと同等の業務処理を、GCP環境上で正常に実行できる状態にすることを目的とする。



このSkillは、以下の2つのAgentを使用して移行を実施する。

### 1. Migration Agent

Migration Agentはコードの実際の移行を担当する。

- AWS依存のコードを特定する
- AWSの実装をGCP対応に変更する
- RedshiftをBigQueryへ変更する
- S3をGCSへ変更する
- 必要に応じてAWS SDKをGCP SDKへ変更する
- コードを実行する
- エラーを分析する
- エラーの原因となるコードを修正する
- 実行と修正を繰り返す

Migration Agentは実際にコードを変更する。

### 2. Review Agent

Review AgentはMigration Agentが行った変更をレビューする。

- AWS固有の実装が残っていないか確認する
- GCPへの移行が正しく行われているか確認する
- Redshift → BigQueryの変更を確認する
- S3 → GCSの変更を確認する
- AWS SDKやAWS固有APIの残存を確認する
- 元の業務ロジックが維持されているか確認する
- 移行によって新たな問題が発生していないか確認する
- 必要な追加修正を指摘する

Review Agentは原則としてコードを変更しない。




## Workflow

このSkillでは、Code Modify AgentとCode Reviewerを連携させて、AWSからGCPへのコード移行、実行、レビュー、修正を繰り返す。

### 1. Migration Branchの準備

Code Modify Agentが移行作業用の新しいGitブランチを作成し、そのブランチへ切り替える。

以降のコード変更は、すべてこのMigration Branch上で行う。

### 2. Code Migration

Code Modify AgentがMigration Branch上でAWS向けの既存コードをGCP向けに修正する。

主な移行対象は以下とする。

- Redshift → BigQuery
- S3 → GCS
- AWS SDK / API → GCP SDK / API
- AWS固有の認証・設定・データアクセス処理

既存の業務ロジックは可能な限り維持する。

### 3. Review and Execution

Code Modify Agentによるコード修正が完了したら、Code Reviewerを実行する。

Code ReviewerはMigration Branch上の最新コードを対象としてレビューを行い、関連するプログラムやテストを実行する。

Code Reviewerはコードを直接変更しない。

### 4. Error Investigation

実行時にエラーや問題が発生した場合、Code Reviewerが原因を調査する。

エラーメッセージ、Stack Trace、関連コード、データ、設定、およびAWSとGCPの仕様差異などを確認し、問題の原因と必要な修正内容を特定する。

調査結果はCode Modify Agentへフィードバックする。

### 5. Code Fix

Code Modify AgentはCode Reviewerから受け取った調査結果に基づいて、Migration Branch上のコードを修正する。

修正後、再度Code Reviewerを実行する。

### 6. Iteration

以下のサイクルを、問題が解決するまで繰り返す。

Code Modify Agent
→ Code Reviewer
→ Execute
→ Error Investigation
→ Code Modify Agent
→ Code Reviewer

Code Reviewerが問題なしと判断した場合、移行作業を完了とする。

### 7. Completion

以下を確認できた時点でMigrationを完了とする。

- AWS依存の必要なコードがGCP向けに移行されている
- RedshiftがBigQueryへ移行されている
- S3がGCSへ移行されている
- 既存の業務ロジックが維持されている
- 関連するプログラムまたはテストが正常に実行できる
- Code Reviewerによるレビューで重大な問題がない
